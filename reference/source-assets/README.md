# Source Asset Library

This folder is the local source-of-truth ingest point for raw project assets that originally lived in Downloads, chat attachment folders, or other ad hoc locations.

## Purpose

- keep future content work anchored to one stable project path
- reduce dependence on compressed chat memory
- preserve original inputs while the Astro content system evolves

## Structure

- `raw/`
  - local copied source files grouped by asset type
  - intentionally ignored by Git via the local `.gitignore`
  - safe to expand as more reports, decks, PDFs, and HTML references arrive
